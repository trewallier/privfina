# Bónusz Magyar Állampapír (BMÁP)

This folder contains the DKJ-linked variable-rate government-security pilot product specification.

BMÁP differs from PMÁP in its reference base: it uses a DKJ auction-yield-based benchmark rather than a prior-year inflation benchmark.

Worked examples in this folder use explicit DKJ base-yield inputs instead of external market-data integration.

Future work can extend this product type with richer series-level metadata and data-source integration behavior.
